Browser Extension

Get the same Fix Grammar / Rewrite / Professional / Concise / Friendly actions inside Chrome or Edge — in Teams-in-browser, Zoho Desk, Gmail, or any editable text field.

1. Locate the extension folder

The extension ships as a plain folder alongside this app — nothing to download separately.

Running in a browser tab right now, so WriteMate can't open the folder for you — navigate to the path above yourself in your file manager.

2. Load it in Chrome or Edge

Chrome/Edge don't let any outside app do this step automatically (browser security) — it's a one-time, ~30 second manual step:

  1. Open chrome://extensions (Chrome) or edge://extensions (Edge) in your browser.
  2. Turn on Developer mode (top-right toggle).
  3. Click Load unpacked.
  4. Select the folder you opened in step 1.
  5. You should see a WriteMate AI icon appear in your extensions list.

3. Use it

Click into any text field on a page, look for the ✨ badge, and click it for the same actions available here. Per-site enable/disable and connection status are in the extension's own popup (click its toolbar icon).
